# 量潮数据工作教程

## 学完以后你能做什么

学完本教程，你应该能够独立完成一个简单的数据服务订单的基本流程：

**理解需求 → 确认范围 → 拆解任务 → 调用标准单元 → 检查结果 → 完成交付。**

具体来说，你应该会：

1. 把客户的模糊需求整理成明确需求
2. 判断需求属于哪个标准业务单元
3. 把一个订单拆成若干执行任务
4. 为任务定义验收标准
5. 按标准执行并记录过程
6. 发现异常并及时升级
7. 完成内部验收
8. 完成最终交付

## 怎么学

全教程用同一个案例贯穿：一家科技公司希望长期跟踪 300 个海外科技网站，每天获取最新文章，并整理成结构化数据。每一章推进这个案例的一个环节，最后一章把从客户第一句话到最终交付的全过程连起来走一遍。

本教程只教「照着做」。每一步都给你：要做的动作、要问的问题、判断规则、以及要产出的东西。读完每一章，你应该能说出「这一章的输出物是什么」——说不出，就还没读完。
