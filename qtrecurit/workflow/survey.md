# 发送准入问卷

本教程说明招聘流程中「发送准入问卷」这一步怎么做、为什么这么做、哪些地方要判断。

## 这一步在流程中的位置

投递筛选 → **发送准入问卷** → 回收问卷 → 初筛评估 → 面试

问卷是筛选的第一道门槛。候选人完成问卷后，我们才有足够的信息做初筛判断。未在 3 个工作日内提交的，视为放弃。

## 发送时机

收到投递后尽快发送，最好当天。候选人投递时热度最高，拖久了会流失。不要积压。投递量大的时候更不能拖，积压意味着最认真的候选人反而等最久

## 操作流程

### 1. 确认候选人信息

从 HR 邮箱查看投递邮件：

```bash
lark-cli mail +triage --mailbox hr@quanttide.com --max 10
```

邮件主题通常包含候选人姓名、岗位和实习时长，例如「数据工程师-张三-清华大学-6个月」。你需要从邮件中提取：

- **姓名** — 后续所有沟通用的名字
- **邮箱** — 发送问卷的目标地址
- **岗位** — 确认投递的是哪个岗位

如果邮件信息不全（缺少邮箱或岗位），先在邮件列表里翻找或等待补充，信息不全不要发问卷。

### 2. 确认问卷链接

问卷链接会自动从 HR 邮箱缓存。确认链接是否就绪：

```bash
qtrecurit cache show-survey
```

如果没有链接或链接过期，手动刷新：

```bash
qtrecurit cache refresh-survey
```

### 3. 发送问卷

```bash
qtrecurit access survey \
  --to candidate@example.com \
  --name 张三
```

CLI 会通过 `hr@quanttide.com` 发出问卷通知邮件。发送后自动将投递邮件归档到「已发送问卷」文件夹，并标注为已读（移除 UNREAD 标签）。

### 4. 验证发送

CLI 发送后会自动验证并在输出中返回结果。确认输出中有 `✓ 已发送` 和收件人信息。
