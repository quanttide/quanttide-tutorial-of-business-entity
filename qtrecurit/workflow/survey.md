# 发送准入问卷

本教程说明招聘流程中「发送准入问卷」这一步怎么做、为什么这么做、哪些地方要判断。

## 这一步在流程中的位置

投递筛选 → **发送准入问卷** → 回收问卷 → 初筛评估 → 面试

问卷是筛选的第一道门槛。候选人完成问卷后，我们才有足够的信息做初筛判断。未在 3 个工作日内提交的，视为放弃。

## 发送时机

收到投递后尽快发送，最好当天。候选人投递时热度最高，拖久了会流失。不要积压——投递量大的时候更不能拖，积压意味着最认真的候选人反而等最久。

## 操作方法

### 1. 确认候选人信息

从 HR 邮箱的投递邮件中提取三项信息：姓名（后续所有沟通用的名字）、邮箱（发送问卷的目标地址）、岗位（确认投递的是哪个岗位）。邮件主题通常包含候选人姓名、岗位和实习时长，例如「数据工程师-张三-清华大学-6个月」。

判断原则：信息不全不要发问卷。缺少邮箱或岗位时，先在邮件列表里翻找或等待补充。

### 2. 确认问卷链接

问卷链接从 HR 邮箱的缓存中读取，发送前先确认链接是否就绪。没有链接或链接过期时，刷新缓存重新获取后再发送。

### 3. 发送问卷

向候选人邮箱发送问卷通知邮件，发送方统一为 `hr@quanttide.com`，保证候选人收到的发件人一致。发送后投递邮件自动归档到「已发送问卷」文件夹并标注已读，防止重复处理。

### 4. 验证发送

发送后核对结果：确认已发送标志和收件人信息正确。验证通过才算是完成了这一步，不要发完就关掉。
